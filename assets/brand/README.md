# Biira Bank

Biira Bank is the fictional regional bank both lab repositories are built for: this one, its identity estate, and [enterprise-security-homelab](https://github.com/noble-antwi/enterprise-security-homelab), the network and infrastructure it runs on. Working to one named organisation keeps the two consistent: one domain, one set of users, one mark.

The mark is a vault door inside a shield. The shield is the protected boundary and the vault door is the controlled way through it, which reads as authentication and authorisation here and as network segmentation in the infrastructure repository.
